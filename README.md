# Сумма двоичных кодов по правилу чётности

Задача: просуммировать коды по правилу чётности (сложение по модулю 2, XOR):

```
010101100011
111110001100
000010001010
```

В каждом разряде результат равен 1, если среди слагаемых нечётное число единиц, и 0, если чётное.

## Запуск

```bash
python parity_sum.py
```

## Результат

```
  010101100011
  111110001100
  000010001010
  ------------
  101001100101
```
